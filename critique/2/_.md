# End-User Test — First Impressions

Fresh user, knows to use `nimble run`. Running from repo root.

## Step 1: "How do I run nimo?"

```bash
$ nimble run nimo --help
Info: using /nix/store/.../bin/nim for compilation
   Building nico/nimo using c backend
 Nim Output ...
nimo -- RWKV inference CLI

Commands:
  generate     Generate text from a prompt
  quantize     Convert model quantization
  harness      Interactive chat harness
  chat         Simple chat
  bake         Bake model state
  workspace    Workspace management
  planner      Show plan for a goal
  new          Create session from goal
  run          Execute a plan
  story        Story pipeline
  unit         Run the unit test suite
  doctor       Check environment health
  eval         (alias) Run the unit test suite
  model-eval   Run model behavior evals

Usage:
  nimo generate --backend cuda --model <path> --prompt "Hello"
  ...
```

**Finding:** 
- First run compiles from source (~2-3s). Subsequent runs use cache.
- Help is clear and shows examples.
- `doctor` command is a nice touch for first-time users.
- `eval` alias is confusing — should just be `unit`.

## Step 2: "Let me check my environment"

```bash
$ nimble run nimo doctor
[doctor] NIMO Environment Health Report
=====================================
[OK] Models directory exists: models
[OK] librwkv.so found on loader path
[gpu] ERROR — GPU unusable: cuInit failed with code 34
[WARN] GPU unusable
```

**Finding:** GPU is currently in a bad state (known issue on this hybrid-graphics laptop). The error message is clear but doesn't suggest the fix. Should mention `nvidia-smi` or reboot.

## Step 3: "Let me try CPU instead"

```bash
$ nimble run nimo generate --backend cpu --prompt "Hello" --max-length 5
```

**Finding:** Need to test this next. CPU should work even when GPU is broken.

**Finding:**
- CPU works perfectly. Generated "Hello-World-Android-" (5 tokens) in 4.04s.
- Output is visible immediately, not streaming but single burst.
- No verbose compilation warnings needed on subsequent runs (cached).
