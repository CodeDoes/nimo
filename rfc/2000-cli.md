# 2000 — CLI

Command surface. What you get with `nimo --help`.

## Commands

```
nimo --help
nimo --version
```

## Chat

```
nimo chat [OPTIONS] [MODEL] [VOCAB] [STATE]
```

Options:
- `-w, --workspace PATH` — use specific workspace
- `--reset` — reset conversation
- `--quit` — exit chat

## Generate

```
nimo generate [OPTIONS] PROMPT [MODEL] [VOCAB] [LENGTH]
```

Options:
- `--length N` — max tokens (default: 60)
- `--temp F` — temperature (default: 0.7)
- `--topp F` — top-p (default: 0.7)

## Bake

```
nimo bake [OPTIONS] PROMPT [MODEL] [STATE] [VOCAB]
```

Options:
- `--output PATH` — output state file (default: baked_state.bin)

## Dashboard

```
nimo dashboard [OPTIONS] [MODEL] [VOCAB]
```

Options:
- `-w, --workspace PATH` — use specific workspace

## Run

```
nimo run [OPTIONS] PIPELINE
```

Options:
- `-w, --workspace PATH` — use specific workspace

## Workspace

```
nimo workspace --help
nimo workspace create [OPTIONS] [NAME]
nimo workspace list
nimo workspace use PATH
nimo workspace remove PATH
```

Workspace create options:
- `--set-default` — set as default for current directory
