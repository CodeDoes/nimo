# 2000 — CLI

Commands the user types. Each command maps to an executable.

## Commands

```bash
nimo chat                 # Interactive chat
nimo chat -w ~/.ws/myproject   # Chat with specific workspace
nimo generate <prompt>    # One-shot generation
nimo bake <prompt>        # Pre-compute model state
nimo dashboard            # Full-screen TUI
nimo run pipeline.nim     # Execute a pipeline script
nimo workspace create     # Create new workspace
```

## Workspace Modes

```bash
# Release mode — workspace is current directory
$ nimo chat

# Dev mode — workspace is last used
$ nimo workspace create --set-default
# Creates ~/.ws/20240101120000_abc123/

# Explicit workspace
$ nimo chat -w ~/.ws/myproject
```

## Intent to Pipeline

User describes what they want. NIMO creates a pipeline and runs it.

```bash
$ nimo chat
> Write a cyberpunk story about a robot ninja

[nimo] Creating plan...
[nimo] Plan:
  1. Generate wiki: Max
  2. Generate wiki: Rob
  3. Write Chapter 1
  ...

[nimo] ▶ 1/10 Generating wiki: Max...
→ wiki/max.md

[nimo] ✔ 1/10 (0.8s)
```
