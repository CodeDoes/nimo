# 6000 — Source Structure

The actual layout of `src/`. **Status: implemented** — this is a map of the
real code, not a wish-list.

## Top-level layout

```
src/
  nimo.nim            # CLI dispatcher (workspace/story handled inline)
  config.nim          # defaults + nimo.json + env overrides
  cli.nim             # colored output helpers (printInfo, printError, banner)
  logger.nim          # session/run logging helpers
  macros.nim          # checkOk, timeBlock, benchmarkStep

  # Backend (RFC 7500)
  rwkv.nim            # FFI bridge + selectBackend/bindBackend (single switch point)
  rwkv_cpu.nim        # CPU backend record
  rwkv_cuda.nim       # CUDA backend record
  rwkv_vulkan.nim     # Vulkan backend record
  gpu.nim             # NVIDIA driver probe + decideGpu
  rwkv/
    backend/types.nim
    backend/cpu/cpu_backend.nim
    backend/cuda/cuda_backend.nim
    backend/vulkan/vulkan_backend.nim
    model/header.nim      # GGML file header
    quant/cache.nim       # model cache (raw -> quantize -> cache)
    state/cache.nim       # state cache (bake + resume)
    generate/…            # generation helpers

  # Inference tools
  session.nim         # low-level session (model+state+logits+rng, generateTurn)
  tokenizer.nim       # vocab encode/decode
  sampling.nim        # temperature/top-p sampling
  generate.nim        # one-shot generate CLI
  quantize.nim        # quantize CLI
  chat.nim            # interactive chat CLI
  bake_state.nim      # state baker CLI
  main.nim            # smoke test
  nimwave_app.nim     # TUI dashboard

  # Harness / agent layer
  session_manager.nim # message tree, tool registry, JSONL save
  harness.nim         # the agent loop (tool parsing, dispatch, iteration guard)
  pipeline.nim        # run_pipeline tool (generate/summarize/extract steps)

  # Project layer
  workspace.nim       # ~/.ws/<name>/ workspaces (dirs, config.toml, outline)
  nimo_folder.nim     # ./.nimo/ app folder (state/cache/logs/sessions/pipelines)
  story.nim           # story pipeline (outline/chapters/validate/critique)
  session_branch.nim  # conversation branches
  report.nim          # session/workspace/story reports
  system_instructions.nim  # workload instruction sets
  context_state_cache.nim  # combined state+model cache with stats

  # Memory
  fiaas.nim           # vector store (hash embeddings + cosine search)
  memory.nim          # MemoryStore wrapper (characters, relevant context)

  # Tests
  evals.nim           # 34 offline checks (nimo eval)
  test_rwkv_full.nim  # model round-trip test
  test_tokenizer.nim  # tokenizer round-trip test
```

## Dependencies (roughly)

```
nimo.nim ──> build/ binaries (generate, quantize, harness, chat, bake, evals)
harness.nim ──> session_manager ──> session.nim ──> rwkv.nim ──> librwkv.so
pipeline.nim ──> session_manager (uses the model through the session)
story.nim ──> workspace.nim + session_manager
memory.nim ──> fiaas.nim + workspace.nim
report.nim ──> session_manager + workspace + story
context_state_cache.nim ──> state_cache + model_cache + session_manager
```
