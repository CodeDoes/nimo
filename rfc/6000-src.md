# 6000 — Source Structure

Desired layout for the project.

```
lib/
  rwkv.so           # Base engine
  rwkv_cuda.so      # CUDA backend
  rwkv_vulkan.so    # Vulkan backend
  nimo.so           # Shared Nim library

app/
  cli.nim           # CLI entry point
  server.nim        # Network server
  client.nim        # Network client
  session.nim       # Session management
  rwkv.nim          # FFI bridge
  model.nim         # Model abstraction
  tokenizer.nim     # Tokenization
  protocol/
    user_intent.nim   # Intent → pipeline
    just_chatting.nim # Chat with tools
    workspace_related.nim # Workspace ops
    story_related.nim   # Story generation
```

## Current vs Desired

| Current | Desired |
|---------|---------|
| `src/` (flat) | `lib/`, `app/`, `protocol/` |
| `rwkv.nim` | `lib/rwkv.so` + `app/rwkv.nim` |
| `session.nim` (raw inference) | `app/session.nim` (message model) |
