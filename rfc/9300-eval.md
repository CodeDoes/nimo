# Eval

Testing if the model can do the task required of it.

## What to evaluate

| Capability | Test | Pass criteria |
|------------|------|---------------|
| Tool calling | Prompt with tool spec, check output has `<tool_call>...</tool_call>` | Correct tool, correct args |
| Think blocks | Prompt requiring reasoning, check for `` | Contains thinking content |
| Multi-turn | 3+ turn conversation | Consistent context, no degradation |
| Stop sequences | Prompt with stop pattern | Stops at correct point |
| Speed | Generate 100 tokens | < X ms/token |

## Workflow

```
1. Load benchmark dataset
2. Run model on each example
3. Check output against expected
4. Report pass/fail per capability
```

None. `test_rwkv_full.nim` tests FFI, not model capabilities.
