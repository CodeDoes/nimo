# 9300 — Eval

Test if the model can do the required tasks.

## Example: tool calling

```nim
# Input
System: You have tool get_weather(location)
User: What's the weather in Boston?

# Expected output contains:
<tool_call>{"get_weather": {"location": "Boston, MA"}}</tool_call>

# Pass: output has correct tool name + args
```

## Example: think blocks

```nim
# Input
User: Why is the sky blue?

# Expected: assistant thinks before answering
Assistant: 
The sky appears blue because...
```

## Metrics

- Tool call accuracy: correct tool + args
- Think presence: `` parsed
- Multi-turn consistency: 3+ turns, no context loss
