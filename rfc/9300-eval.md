# Eval

## Purpose

Evaluate model output quality and performance.

## Eval Metrics

- **Perplexity** — language model quality
- **Token throughput** — tokens/sec
- **Time-to-first-token** — latency
- **Output quality** — human/LLM-evaluated
- **Tool call accuracy** — correct parsing and execution

## Eval Workflow

```
1. Load benchmark dataset
2. Run model on each example
3. Collect outputs
4. Compute metrics
5. Generate report
```

## Current Implementation

`src/macros.nim` — `benchmarkStep` macro for timing.
`src/test_rwkv_full.nim` — integration tests.

## RFC Scope

- Benchmark dataset format
