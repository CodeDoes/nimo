# Chat Pipeline

Interactive chat pipeline with tool calling and think blocks.

## Flow

```
User input
  → encode "User: {input}\n\nBot:"
  → evalSequenceInChunks
  → generateTurn (sample → eval loop)
  → parse response for:
      -  (think part)
      - <tool_call>...</tool_call> (tool_call part)
      - text (assistant reply)
  → if tool_call: dispatch tool, get result
  → inject tool_result into context
  → continue loop until no more tool calls
```

## Message Format

See [1100-message-format.md](1100-message-format.md) for part types.

## Example Pipeline

```nim
# Chat session pipeline
let session = generate("User: Hi!\n\nBot: Hello! How can I help you today?\n\n", target = "session/state.bin")

let reply = generate(
  """
  System: You are a helpful assistant
  User: What's the weather in Boston?
  """,
  target = "chat/response.md"
)

# Parse reply for tool calls
let parsed = extract(reply, "tool_calls, think, text")
```

## Tool Dispatch

When model emits ``:
1. Parse tool name + arguments from JSON
2. Execute tool (via registered handlers)
3. Inject `\n\nUser: <tool_result>{output}</tool_result>\n\nAssistant:`
4. Continue generation
