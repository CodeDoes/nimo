# 9400 — Test

Test if the harness (code) is working. **Status: implemented** — `src/unit.nim` (offline suite), `src/test_tokenizer.nim`, `src/test_rwkv_full.nim`.

## Example: tokenizer round-trip

```nim
import ./tokenizer

test "encode/decode round-trip":
  let tok = loadWorldTokenizer("vocab.txt")
  let orig = "Hello 世界!"
  let tokens = tok.encode(orig)
  let decoded = tok.decode(tokens)
  assert decoded == orig
```

## Example: model load

```nim
test "model loads and eval works":
  let model = initRwkvModel("model.bin")
  let state = model.newState()
  let logits = model.newLogits()
  assert model.eval(0.uint32, state, logits)
```
