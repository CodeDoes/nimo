# Test

Testing if the harness (code) is working.

## Test Categories

| Category | What it tests | Example |
|----------|--------------|---------|
| Unit | Individual functions | tokenizer encode/decode round-trip |
| Integration | Components working together | model load → encode → generate |
| E2E | Full CLI commands | `nimo chat` starts and responds |
| Regression | Previously working features | re-run old test suite |

## Current Implementation

- `src/test_tokenizer.nim` — tokenizer round-trip
- `src/test_rwkv_full.nim` — FFI integration tests
- `nimble test` task

## RFC Scope

- Test runner (Nimble task)
- Test data fixtures
- CI integration
- Coverage reporting
