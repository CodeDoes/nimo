# 1200 — Chat

The interactive chat workflow. **Status: implemented** in `src/chat.nim`.

## What it is

A simple REPL: you type, the model answers, repeat. No tool calling here —
that's the harness (see [3400-agent.md](3400-agent.md)). Chat keeps a running
model state so the conversation accumulates context.

## How it works (step by step)

1. **Load**: parse args (`--backend`, `--device`, `--lib`, positional
   model/vocab/state paths), resolve the backend, bind the library, load the
   model and tokenizer.
2. **Seed**: evaluate a tiny greeting exchange ("User: hi / Bot: Hello!...")
   into the state so the model starts in the right mood. If a baked state file
   was given, it's loaded instead (see [8000-state-bake.md](8000-state-bake.md)).
3. **Loop**:
   - print `User: ` and read a line
   - `/quit` or `/exit` → goodbye, stop
   - `/reset` → reload the model + re-seed, start over
   - otherwise → `generateTurn(inputLine)`: the input is encoded, evaluated,
     and tokens are sampled until the stop token; the reply is printed.
4. Each interaction is written to the session log (`logChatInteraction`).

## Sampling defaults

Temperature 0.7, top-p 0.7 (from config). The RNG is seeded per session so
conversations are reproducible-ish.

## Commands inside chat

| Command | Effect |
|---------|--------|
| `/quit`, `/exit` | leave the chat |
| `/reset` | start a fresh session |
