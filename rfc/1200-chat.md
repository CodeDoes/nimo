# 1200 — Chat

Conversational workflow. Low latency, tight tool integration, aggressive history pruning.

## Config

```toml
[workload.chat]
temperature = 0.2
top_p = 0.9
max_tokens = 500
context_pruning = "aggressive"  # trim old messages
tool_integration = "full"       # all tools available
```

## Flow

```
user message → model → think → text/tool_call → tool_result → model → text
```

## Example Session

```jsonl
{"type":"session","version":3,"id":"...","cwd":"/home/kit/dev/nimo","workload":"chat"}
{"type":"message","id":"msg1","role":"user","content":[{"type":"text","text":"What's the weather?"}]}
{"type":"message","id":"msg2","role":"assistant","content":[{"type":"thinking","thinking":"User wants weather. I should call the tool."},{"type":"toolCall","id":"call1","name":"get_weather","arguments":{"location":"Boston"}}],"stopReason":"toolUse"}
{"type":"message","id":"msg3","role":"toolResult","toolCallId":"call1","content":[{"type":"text","text":"72°F, sunny"}],"isError":false}
{"type":"message","id":"msg4","role":"assistant","content":[{"type":"text","text":"The weather in Boston is 72°F and sunny."}],"stopReason":"stop"}
```

## History Management

- Keep last 20 messages in context
- Prune older messages aggressively
- System prompt always present
- Recent tool results preserved

## Tools Available

| Tool | Purpose |
|------|---------|
| `bash` | Execute commands |
| `read` | Read files |
| `write` | Write files |
| `get_weather` | Weather lookup |
| `calculator` | Math operations |
