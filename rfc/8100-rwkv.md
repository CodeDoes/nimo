# 8100 — RWKV

RWKV model details.

## Sampling (src/sampling.nim)

Logit sampling for generation: temperature scaling, top-P (nucleus), and the
RNG seeded per session. Exposed via config `temperature` / `topP` (see
[4000-config.md](4000-config.md)).

## Quantization

- Q4_0: 4-bit quantization, good balance of speed/quality
- Q5_0: 5-bit, slightly better quality
- Q8_0: 8-bit, near-float quality, larger

> Our shipped default is **Q4_K** (best quality per bit of the 4-bit family) —
> see **[8150-quantization.md](8150-quantization.md)** for the full policy:
> formats, the `.pth`→FP16→quant workflow, the file header layout, the VRAM
> budget/clamp, and model-file naming.
