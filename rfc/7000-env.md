# 7000 — Environment

Build and runtime requirements.

## Engines

| Engine | Library | Requirements |
|--------|---------|--------------|
| CUDA | `rwkv.cpp/librwkv.so` (ggml-cuda) | NVIDIA GPU, CUDA toolkit |
| Vulkan | `rwkv.cpp/librwkv.so` (ggml-vulkan) | Vulkan drivers |
| CPU | `rwkv.cpp/librwkv.so` | OpenMP, SSE/AVX |

Engine choice is decided at runtime by `src/gpu.nim` — see
[7500-gpu.md](7500-gpu.md) for detection, the config-gated CPU fallback, and
the VRAM-safe layer clamp.

## Memory

- **This machine**: RTX 2050 with **4 GB** VRAM. The default **Q4_K** model is
  ~2.2 GB and fully offloads; the FP16 (5.9 GB) does not (harness clamps layers).
- **RAM**: 8GB+ for model + state
- **Storage**: 10GB+ for models + vocab
