# 7000 — Environment

Build and runtime requirements.

## Engines

| Engine | Library | Requirements |
|--------|---------|--------------|
| CUDA | `lib/rwkv_cuda.so` | NVIDIA GPU, CUDA toolkit |
| Vulkan | `lib/rwkv_vulkan.so` | Vulkan drivers |
| CPU | `lib/rwkv.so` | OpenMP, SSE/AVX |

## Memory

- **VRAM**: 6GB+ for 2.9B model (Q4 quantized)
- **RAM**: 8GB+ for model + state
- **Storage**: 10GB+ for models + vocab

## Model Paths

```
MODEL_ORIGIN_URL=https://huggingface.co/...
DOWNLOAD_FOLDER=~/models/
QUANTIZE_FOLDER=~/models/quantized/
```
