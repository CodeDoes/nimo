# 3100 — Chat Pipeline

Interactive chat with tool calling and think block parsing.

## Flow

```
User types input
  → NIMO encodes: "User: {input}\n\nBot:"
  → Model generates response
  → NIMO parses response:
      - "..." → think part (hidden)
      - "<tool_call>...</tool_call>" → tool call (dispatch to handler)
      - rest → text part (show to user)
  → If tool call: run handler, inject result, continue
```

## Example Session

```
User: What's the weather in Boston?

[Assistant thinks...]
<tool_call>{"get_weather": {"location": "Boston, MA"}}</tool_call>

[User receives tool result]
<tool_result>72°F, sunny</tool_result>

Assistant: The weather in Boston is 72°F and sunny.
```

## Tool Dispatch

When model calls a tool:
1. Parse tool name + JSON args
2. Run registered handler
3. Inject `\n\nUser: <tool_result>{output}</tool_result>\n\nAssistant:`
4. Continue generation
