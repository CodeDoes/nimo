# 3100 — Chat Pipeline

The interactive chat loop with tool calling. **Status: implemented** in
`src/harness.nim` (the harness REPL) and `src/chat.nim` (plain chat).

## Plain chat (no tools)

`src/chat.nim`:

```
User types input
  → session.generateTurn(input):
      encode "User: {input}\n\nBot:"
      evaluate prompt in chunks
      sample tokens until stop token / max length
  → print reply
```

Supports `/reset` (reload model + re-seed) and `/quit`.

## Harness chat (with tools)

`src/harness.nim` adds the tool loop on top:

1. Wrap input with the system prompt that teaches the `[tool]` format.
2. Model generates a reply.
3. Parse the reply for tool calls (3 forms — see
   [1100-message-format.md](1100-message-format.md)).
4. No call → reply is the final answer.
5. Call found → record call, run the registered tool (run_pipeline), record
   the result, feed it back, continue. Up to 8 iterations.

## Tool dispatch (as coded)

```
parseToolCalls(reply)      # [tool] / <tool_call> / bare JSON
executeTool(toolCallId, name, args)   # look up in session.tools registry
  → handler returns a string (the tool result)
addToolResult(toolCallId, result)     # record as a message
context = natural_text + feedback + "Now answer the user's question..."
```

The registry has one tool today: `run_pipeline` (see
[3000-pipeline.md](3000-pipeline.md)).
